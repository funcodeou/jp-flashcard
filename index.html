2. 導覽列與首頁圖示說明

  • 📍（目前所在地）：顯示當前環日本抵達的縣市名稱，點擊可開啟環日本地圖與里程碑相簿。
  • 🏠（首頁）／ 📖（操作手冊）／ 🔗（連線設定）：返回首頁、檢視使用說明，或設定 Google Apps Script 試算表 API 網址。
  • ＋（添加主題）／ ✏️（編輯主題）：連結工作表，設定出題欄位（需含一組 [ ]）、提示欄位與答案展示欄位。
  • 🧹（清除勾選紀錄）／ 🗑️（刪除勾選主題）：勾選主題方框後點擊，可清除練習紀錄或移除主題卡片。
  • 🚩（標註修訂清單）：查看答案卡右上角標記為「需要修訂」的卡片。

3. 閃卡資訊列與操作

  • 卡片資訊列：左上角迴轉箭頭為結束返回首頁；中間顯示題數進度；右側顯示當前模式圖示與累積里程，以及 💪 練習次數、✓ 答對次數、✕ 答錯次數。
  • ▶（圓形播放答題鈕）：位於「出題卡片」標籤正下方，輸入答案後點擊即可送出比對；點擊卡片空白處則可直接查看答案（計為答錯）。
