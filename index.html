2. 導覽列與首頁圖示說明

  • 📍（目前所在地）：顯示當前環遊日本抵達的縣市名稱，點擊可開啟環日本地圖與姆明家族旅行進度。
  • 🎨（調色盤）：提供彩虹七色（紅、橙、黃、綠、藍、靛、紫）各三種日本傳統色搭配，可自由切換出題卡與答案卡的配色。
  • 🏠（首頁）／ 📖（操作手冊）／ 🔗（連線設定）：返回首頁、檢視使用說明，或設定 Google Apps Script 試算表 API 網址。

3. 出題卡與答案卡操作說明

  • 出題中卡片：點擊播放按鈕（▶）或按 Enter 送出答案；在卡片空白處按兩下（雙擊）可直接翻至答案揭曉卡片（計為答錯）。
  • 答案揭曉卡片：左側並排重答（🔄）與下一張（→）純圖示按鈕；右側為醒目綠色（答對）／紅色（答錯）圓形狀態圖示，點擊可展開／收合本次作答對比與里程變化詳情。
